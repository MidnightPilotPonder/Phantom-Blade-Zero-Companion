## ✨ What is this?

The **Phantom Blade Zero Companion** is a lightweight, Windows‑only utility that lives beside your game and gives you instant access to the information you need while you’re hunting down those high‑score runs.

- **Live Stat Tracker** – see damage, accuracy, and cooldowns in real‑time.
- **Quest & Mission Manager** – mark objectives, set reminders, and track completion percentages without leaving the game.
- **Quick‑Launch Overlay** – open maps, inventory, or community guides with a single hotkey.
- **Customizable Themes** – match the UI to your personal taste or the game’s aesthetic.

All features are designed to be **non‑intrusive** and **resource‑friendly**, so your frame‑rate stays pristine.

---

## 🚀 Getting Started

1. **Download** the latest build from the official page.
2. Run the installer and follow the on‑screen wizard (default settings work for most users).
3. Launch **Phantom Blade Zero** – the companion will auto‑detect the game process and attach the overlay.
4. Open the settings ( `Ctrl + Shift + C` ) to tweak hotkeys, UI layout, and telemetry options.

> **Tip:** Keep the companion updated to enjoy new features and bug fixes as soon as they’re released.
